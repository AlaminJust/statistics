# workspace/ — my own work

This folder mirrors `curriculum/`. Everything here is written by me, and git tracks every change.

Start a lesson with:

```bash
make lesson L=02-descriptive-statistics/03-measures-of-spread
```

which creates:

```text
workspace/02-descriptive-statistics/03-measures-of-spread/
├── notes.md        ← my explanation in my own words (from templates/lesson-notes.md)
└── exercises.py    ← my answers (from templates/lesson-exercises.py)
```

Add any extra files you like (scratch scripts, hand-written notes as photos, notebooks). Commit after each step of the
study loop in [docs/study-method.md](../docs/study-method.md).
