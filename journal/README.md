# journal/ — weekly learning log

One file per ISO week, created with `make journal` (for example `2026-W44.md`). Write it at the end of every week,
in 10–15 minutes, and commit it with `journal: week 2026-W44`.

Why bother: it turns "I studied a lot" into evidence of what you learned, what was hard, and how many hours you put
in. Reading back over old entries is also the fastest way to find which topics need review.
