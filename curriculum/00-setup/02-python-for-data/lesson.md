## Why this matters

Statistics in practice means computing on **many numbers at once**. Three libraries do almost all of it:

| Library | Think of it as | You use it for |
| --- | --- | --- |
| NumPy | a calculator for whole lists of numbers | arithmetic, random numbers, linear algebra |
| pandas | a spreadsheet you control with code | loading data, filtering rows, grouping |
| matplotlib | graph paper | histograms, scatter plots, every figure in a paper |

Every ML library (scikit-learn, PyTorch) takes NumPy arrays or pandas tables as input, so these skills carry straight
through to the end of the course.

## 1. Arrays: arithmetic on everything at once

A NumPy **array** holds numbers of one type and applies an operation to *every element*:

```python
import numpy as np
scores = np.array([62, 75, 75, 80, 84, 88, 91, 97])
scores + 5       # array([ 67,  80,  80,  85,  89,  93,  96, 102])
scores * 2       # array([124, 150, 150, 160, 168, 176, 182, 194])
```

A plain list behaves differently: `[62, 75] * 2` gives `[62, 75, 62, 75]` (it *repeats* the list) and
`[62, 75] + 5` is an error. This element-by-element behaviour is called **vectorisation**. It is also much faster:
in `examples.py`, summing a million numbers is about 300 times faster with `big.sum()` than with a `for` loop.

Every array has a **dtype** (type of its elements, e.g. `int64`, `float64`) and a **shape** (`(8,)` means one
dimension with 8 elements).

## 2. Picking values: index, slice, mask

```python
scores[0]       # 62        first element (Python counts from 0)
scores[-1]      # 97        last element
scores[:3]      # [62 75 75] elements 0, 1, 2 (the end index is excluded)
```

A **boolean mask** is an array of `True`/`False` the same length as the data. It is the most important selection tool
in data work:

```python
mask = scores >= 80      # [False False False  True  True  True  True  True]
scores[mask]             # [80 84 88 91 97]   keep only the True positions
mask.sum()               # 5        True counts as 1, False as 0
mask.mean()              # 0.625    the PROPORTION of scores >= 80
```

**Worked example.** What share of these 8 scores is at least 80?
Count by hand: 80, 84, 88, 91, 97 → 5 of 8 = 0.625. `mask.mean()` gives the same, because the mean of 0s and 1s is the
proportion of 1s. You will use this trick constantly: *the mean of a 0/1 variable is a proportion.*

## 3. Aggregations and axes

```python
scores.sum()     # 652
scores.mean()    # 81.5     = 652 / 8
scores.min(), scores.max()   # 62, 97
```

A **2-D array** is a table. Rows are usually *observations* (students), columns are *variables* (tests):

```python
tests = np.array([[70, 80, 90],     # student A
                  [60, 65, 70],     # student B
                  [85, 95, 75]])    # student C
tests.mean(axis=1)   # [80. 65. 85.]          one mean per student (collapse the columns)
tests.mean(axis=0)   # [71.67 80.   78.33]    one mean per test    (collapse the rows)
```

Memory aid: **`axis` is the direction that disappears.** `axis=0` collapses rows, leaving one value per column.

Check by hand: student A's mean is (70 + 80 + 90) / 3 = 80. Test 1's mean is (70 + 60 + 85) / 3 = 215 / 3 ≈ 71.67.

## 4. pandas DataFrames

A **DataFrame** is a table with named columns. Each column is a **Series**.

```python
import pandas as pd
df = pd.read_csv("data/students.csv")
df.shape          # (200, 8): 200 rows (students), 8 columns (variables)
df.head()         # first 5 rows
df.dtypes         # type of each column
```

`data/students.csv` is a **synthetic** dataset (generated by `data/make_students.py`), so we know the truth behind it.
Columns: `student_id`, `program` (Science/Arts/Commerce), `year` (1–4), `study_hours` (per week), `sleep_hours` (per
night), `commute_minutes`, `tutoring` (yes/no), `exam_score` (0–100).

### Selecting and filtering

```python
df["exam_score"]                      # one column (a Series)
df[["study_hours", "exam_score"]]     # several columns (a DataFrame) — note the double brackets
df[df["program"] == "Science"]        # rows where the condition is True → 79 students
df[(df["study_hours"] > 15) & (df["sleep_hours"] >= 7)]   # 16 students
```

Combine conditions with `&` (and), `|` (or), `~` (not), and **always put each condition in parentheses**.

### Sorting, summarising, grouping

```python
df.sort_values("exam_score", ascending=False).head(3)
df["exam_score"].describe()            # count, mean, std, min, quartiles, max
df.groupby("program")["exam_score"].mean()
df["tutoring"].value_counts()          # no 140, yes 60
```

`groupby` follows **split → apply → combine**: split the rows by program, compute the mean of each group, combine the
results into one table. The output here:

| program | mean exam_score |
| --- | --- |
| Arts | 64.08 |
| Commerce | 65.02 |
| Science | 63.11 |

### New columns

```python
df["sleep_deficit"] = (8 - df["sleep_hours"]).clip(lower=0)
```

You will see `1.4000000000000004` instead of `1.4` in the output. Computers store decimals in binary, and 0.1 has no
exact binary form, just as 1/3 has no exact decimal form. Tiny errors like this are normal. Never test floats with
`==`; use `np.isclose(a, b)`.

## 5. matplotlib: every figure needs a title and labelled axes

```python
import matplotlib.pyplot as plt
fig, ax = plt.subplots(figsize=(6, 4))
ax.hist(df["study_hours"], bins=20)
ax.set_title("Weekly study hours (200 students)")
ax.set_xlabel("Study hours per week")
ax.set_ylabel("Number of students")
fig.savefig("study_hours_hist.png", dpi=120)
```

- `fig` is the whole image; `ax` is one plotting area inside it. Always draw on `ax`.
- A **histogram** shows how one numeric variable is distributed; a **scatter plot** shows how two relate.
  Module 02 covers both in depth.
- Open `figures/generated/study_hours_hist.png`: most students study 5–12 hours, with a long tail to the right. That
  shape (right skew) will matter in Module 02.

## Common mistakes

| Mistake | What happens | Fix |
| --- | --- | --- |
| `df["a", "b"]` | KeyError | Double brackets: `df[["a", "b"]]` |
| `df[df.x > 1 and df.y < 2]` | ValueError: truth value is ambiguous | `&` with parentheses: `df[(df.x > 1) & (df.y < 2)]` |
| Mixing up `axis=0` and `axis=1` | Wrong-shaped result | "The axis you name disappears" |
| `a == 0.3` for floats | False when you expect True | `np.isclose(a, 0.3)` |
| Plots with no labels | Reader can't interpret them | Always set title, x label, y label |

## Summary

- Arrays apply operations to every element (vectorisation) and are fast.
- Masks select rows; **the mean of a boolean mask is a proportion**.
- `axis=0` → one result per column; `axis=1` → one result per row.
- pandas: `read_csv`, `[[...]]`, boolean filtering, `sort_values`, `describe`, `groupby`, `value_counts`.
- matplotlib: `fig, ax = plt.subplots()`, draw on `ax`, label everything, `savefig`.
