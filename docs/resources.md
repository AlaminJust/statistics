# Free resources by module

Each lesson in this course is self-contained. Use these when you want a second explanation, more practice, or depth.
Links checked on 2026-10-23 (Harvard, Columbia, OpenIntro and Microsoft block automated checks, so those four were not confirmed).

## Starting from scratch (Modules 00–02)

| Resource | Type | Best for |
| --- | --- | --- |
| [Khan Academy — Statistics and Probability](https://www.khanacademy.org/math/statistics-probability) | Course with practice | Extra beginner practice on any topic |
| [OpenIntro Statistics](https://www.openintro.org/book/os/) | Free textbook | A second explanation of descriptive stats and inference |
| [StatQuest with Josh Starmer](https://www.youtube.com/@statquest) | Short videos | Any concept explained visually in 5–15 minutes |
| [Seeing Theory](https://seeing-theory.brown.edu/) | Interactive | Visual intuition for probability and distributions |
| [3Blue1Brown — Essence of Linear Algebra](https://www.3blue1brown.com/topics/linear-algebra) | Videos | Vectors and matrices (Lesson 01.05) |
| [Mathematics for Machine Learning](https://mml-book.github.io/) | Free book | Math toolkit in more depth |
| [Think Stats — Allen Downey](https://allendowney.github.io/ThinkStats/) | Free book + notebooks | Statistics with Python code |
